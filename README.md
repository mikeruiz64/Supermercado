# Inventario y caja de un supermercado

Proyecto final de Estructuras de Datos (E193, 2026B), Unidades Tecnológicas de Santander.

Integrantes: Brayan Nelson Gómez H y Michael Steven Ruiz Diaz.

- **Tabla Hash** con encadenamiento para el inventario.
- **Cola** enlazada (FIFO) para la fila de caja.

## Ejecutar (JDK 17)

```
javac -encoding UTF-8 *.java
java SupermercadoApp
java PruebasSupermercado
```
